# Login & Signup — Split Panel Authentication

A responsive authentication UI built with HTML, CSS, and vanilla JavaScript for the MetaSkillGroup component task.

## Overview

This project features a modern split-panel login and signup interface with a dark theme, gradient overlay, and responsive layout.

## Features

* Login and signup form switching
* Animated split-panel overlay on desktop
* Responsive layout for mobile devices
* Show/hide password controls
* Live password-strength checklist
* Form input validation
* Floating labels and modern styling

> Features listed above should be kept only if they work correctly in your final version.

## Tech Stack

* **HTML5** — Page structure
* **CSS3** — Styling, animations, and responsive layout
* **JavaScript** — Form interactions and validation
* **Google Fonts** — Outfit and Inter
* **Remix Icon** — Interface icons

## Getting Started

1. Clone this repository:
